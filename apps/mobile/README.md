# Mingle mobile

This app uses Expo SDK 57, Expo Router, Amazon IVS Player, and Amazon IVS Chat.

The IVS player contains native code. Expo Go is not supported for the complete app; use an EAS development build or a local native build.

## Environment

```bash
cp .env.example .env.local
```

Replace the example playback, token API, and chat WebSocket URLs with values from your AWS environment.

## Development build

```bash
npx eas-cli@latest login
npx eas-cli@latest build --profile development --platform android
```

For an iOS simulator build, use the `development-simulator` profile. A physical iOS build requires an Apple Developer account.

After installing the development client:

```bash
npm run start
```

## Local native build

Install Xcode or Android Studio first, then run `npm run ios` or `npm run android`. Native directories are generated by Expo and are intentionally ignored.

## Checks

```bash
npm run lint
npm run typecheck
```

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

In the output, you'll find options to open the app in a

- [development build](https://docs.expo.dev/develop/development-builds/introduction/)
- [Android emulator](https://docs.expo.dev/workflow/android-studio-emulator/)
- [iOS simulator](https://docs.expo.dev/workflow/ios-simulator/)
- [Expo Go](https://expo.dev/go), a limited sandbox for trying out app development with Expo

You can start developing by editing the files inside the **app** directory. This project uses [file-based routing](https://docs.expo.dev/router/introduction).
